# Conhecimentos

Esta pasta receberá sínteses temáticas reutilizáveis extraídas de diferentes cursos.

Cada síntese deverá:

- apontar as aulas usadas como fontes;
- separar conteúdo das fontes de inferências;
- registrar conflitos ou diferenças entre fontes;
- mostrar aplicações práticas;
- indicar a data da última revisão.

O índice geral será criado em uma etapa separada.
