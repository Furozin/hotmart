# Aulas — Burguer Artesanal

Cada aula estudada deve ganhar um arquivo próprio nesta pasta.

Formato sugerido:

- fonte: curso, módulo, aula, URL e timestamps;
- resumo curto;
- conceitos;
- aprendizados operacionais;
- aplicações possíveis;
- dúvidas ou pontos a revisar;
- limites: não copiar aula integral, receitas completas protegidas ou transcrições longas.
