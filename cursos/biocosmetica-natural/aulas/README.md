# Aulas — Biocosmética Natural

Esta pasta receberá registros de aulas estudadas.

Para este curso, cada aula deve seguir estes limites:

- registrar fonte, módulo, aula e data de estudo;
- sintetizar em palavras próprias;
- evitar copiar transcrições ou material protegido;
- não registrar fórmulas, dosagens, receitas, passo a passo de fabricação ou instruções de aplicação.
