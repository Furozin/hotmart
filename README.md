# Hotmart — Segundo cérebro

Base de conhecimento dos cursos estudados e de suas aplicações práticas.

## Objetivo

Transformar aulas e materiais autorizados em resumos estruturados, conhecimentos reutilizáveis e ações para a Lotusistemas.

## Estrutura

- `cursos/`: cursos, módulos, aulas e progresso.
- `conhecimentos/`: sínteses temáticas.
- `lotusistemas/`: contexto e aplicações.
- `fontes/`: procedência dos materiais.
- `AGENTS.md`: regras de leitura e atualização da memória externa.

## Fluxo

1. Registrar o curso.
2. Processar a aula com o template.
3. Separar fonte, síntese, inferência e aplicação.
4. Consolidar conhecimentos por tema.
5. Relacionar aplicações à Lotusistemas.
6. Atualizar o índice de conhecimento.

## Importante

O repositório deve permanecer privado quando receber informações internas. Não armazene credenciais nem materiais integrais sem autorização.
