# Fontes

Catálogo de procedência dos conteúdos utilizados.

Registrar:

- curso, professor ou instituição;
- plataforma e URL original;
- módulo e aula;
- data de acesso;
- tipo de material;
- existência de legenda, transcrição ou anexo;
- restrições de uso conhecidas.

Não armazenar credenciais nem copiar materiais protegidos integralmente.
